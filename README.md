# 🗼 Dock — macOS 菜单栏项目启动器

一个轻量级的 macOS 菜单栏工具，集中管理你所有本地 Web 项目。  
不用记端口号，图标一点就能看到、就能打开。

![Dock](./assets/icon.png)

## 为什么需要它？

每天在不同项目间切换，每个都跑在不同端口上——`localhost:3000`、`localhost:5173`、`localhost:8080`……根本记不住。Dock 在菜单栏放一个灯塔图标，下拉就能看到你所有项目的名称、端口、在线状态，点一下用浏览器打开。不用的项目随时删，新项目可以自动扫描添加。

## 功能一览

### 🗼 菜单栏托盘
| 功能 | 说明 |
|------|------|
| 项目列表 | 灯塔图标下拉，显示所有项目及端口 |
| 状态指示灯 | 在线 🟢 / 离线 ⚫，每 30 秒自动刷新 |
| 一键启动 | 点击在线项目 → 浏览器打开 `localhost:{port}` |
| 刷新状态 | 手动重新检测所有端口 |
| 管理入口 | 打开管理窗口 |

### 🔍 端口扫描
| 功能 | 说明 |
|------|------|
| 自动扫描 | 基于 `lsof` 扫描所有本地 TCP 监听端口 |
| 进程识别 | 自动获取进程名称 |
| 路径检测 | 通过 `lsof -p <pid> -d cwd` 获取工作目录 |
| 路径缩写 | `~/` 替代 `/Users/xxx/`，简洁直观 |
| 去重过滤 | 已在项目列表中的端口自动标记「已添加」 |

### 📦 项目管理
| 功能 | 说明 |
|------|------|
| 添加项目 | 名称、端口、描述、项目路径 |
| 编辑项目 | 修改任意字段 |
| 删除项目 | 单删 + 批量删除 |
| 批量添加 | 扫描结果多选 → 一键入库（带路径） |
| 批量删除 | 点击卡片选中（红色高亮）→ 一键删除 |
| 拖动排序 | 拖拽卡片调整顺序，实时保存 |
| 搜索筛选 | 按名称/端口/描述实时过滤 |
| 右键菜单 | 快速打开、编辑、删除 |

### 🎨 视图与主题
| 功能 | 说明 |
|------|------|
| 方形卡片 | 3 列网格布局，信息密度高 |
| 长条列表 | 一行一个，适合项目多时 |
| 深色主题 | 默认暗黑风格 |
| 浅色主题 | 设置中一键切换，主窗口实时同步 |

### 📁 Finder 集成
- 有路径 → 🟢 绿色「打开」，点击在 Finder 中定位
- 无路径 → 灰色禁用，一眼可辨

### ⚙️ 更多
- 配置持久化 → `~/.dock/projects.json`
- 导出/导入 JSON → 备份迁移一键完成
- 开机自启、启动时打开窗口（可选）
- 窗口宽度刚好三列卡片，滚动条自动隐藏

## 安装

### 直接安装（推荐）
1. 从 [Releases](https://github.com/xuhyd-code/dock/releases) 下载最新 DMG
2. 双击打开，拖入 `Applications`
3. 首次打开若提示「无法验证开发者」→ **系统设置 → 隐私与安全性** → 点击「仍要打开」

### 从源码运行
```bash
git clone https://github.com/xuhyd-code/dock.git
cd dock
npm install
npm start
```

## 项目结构

```
dock/
├── main.js          # Electron 主进程（托盘、窗口、IPC）
├── preload.js       # 安全桥接（contextBridge）
├── renderer.html    # 管理窗口（830+ 行单文件）
├── settings.html    # 设置窗口
├── assets/          # 图标（灯塔、模板）
├── package.json     # 依赖 + electron-builder 配置
└── dist/            # 构建产物（DMG）
```

## 技术栈

| 层 | 技术 |
|----|------|
| 壳 | Electron 36 |
| 前端 | 原生 HTML + CSS + JS（零框架） |
| 端口检测 | `lsof` + 子进程 |
| 打包 | electron-builder → DMG |
| 安全 | contextBridge + contextIsolation |

## 安全

- contextBridge 隔离，nodeIntegration 禁用
- HTML 转义使用 `textContent`，防 XSS
- 命令执行仅限固定 `lsof` 调用，无用户输入注入
- 所有外部链接和路径经预定义 IPC 通道
